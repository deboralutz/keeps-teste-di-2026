### Instrução de upload pela interface do GitHub

Abrir esta pasta `prototipo/midia/` na branch `main`; escolher **Add file → Upload files**, selecionar o arquivo MP4 com o nome exato acima e confirmar **Commit changes**. O HTML já aponta para `./midia/01-01-uma-situacao-comum-no-trabalho.mp4` e reconhecerá o vídeo quando estiver nesse endereço, sem necessidade de alterar o código.

A primeira tela sempre oferece transcrição. Até o upload, o player exibirá uma mensagem de indisponibilidade e o texto permitirá a continuidade do exercício.
