# Módulo 6 — Adaptabilidade e aprendizagem contínua

**Duração estimada:** 25 minutos para o módulo completo.  
**Objetivo proposto:** analisar mudanças nas atividades profissionais e propor uma ação viável de desenvolvimento ou melhoria, considerando recursos, condições de aplicação e acompanhamento.
